# TodoList CRUD Application

A full-stack TodoList CRUD application built with **React.js**, **Node.js**, **Express.js**, and **MySQL** with **JWT Authentication**.  
Users can register, login securely, and manage their personal todos.

---

##  Features

- User Registration & Login
- JWT Authentication & Authorization
- Create Todo
- Read Todos
- Update Todo
- Delete Todo
- Protected Routes
- Responsive UI
- REST API Integration
- MySQL Database Storage

---

##  Tech Stack

### Frontend
- React.js
- Axios
- React Router DOM
- CSS / Tailwind CSS

### Backend
- Node.js
- Express.js
- JWT (JSON Web Token)
- bcrypt.js

### Database
- MySQL
